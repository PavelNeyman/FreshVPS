# Провайдеры VPS (оплата из РФ / exit) — снимок 2026-09

**EN:** [../VPS-PROVIDERS.md](../VPS-PROVIDERS.md)

Сводка по открытым рейтингам и тестам. **Не замена** собственному `iperf3`/пингу с вашего оператора.

## Канал: заявленное vs замеры

| Провайдер | Типичный заявленный порт | Публичные замеры (ориентир) | Источник/комментарий |
|-----------|--------------------------|-----------------------------|----------------------|
| **Aeza** | 1–25 Gbit (локация) | Speedtest-снимки до **~700–800 Mbps** DL/UL на отдельных EU-нодах; в маркетинге «гигабит+» | Пользовательские Speedtest (напр. AMS); Хабр сильнее по CPU/disk |
| **Timeweb** | 1 Gbit | В обзорах часто **сотни Mbps–~1 Gbit** DL; UL зависит от тарифа | Хабр NL/RU; сбалансировано |
| **VDSina** | до 1 Gbit | Mid-tier **сопоставим** с Timeweb по сети | Хабр сравнительные |
| **RUVDS** | до 1 Gbit | Дешёвые: **~900 Mbps DL / ~100 Mbps UL**; дороже — ближе к симметрии | Хабр / тесты VDS |
| **FirstVDS** | 100 M–1 G | NL-обзоры: сильный CPU; сеть **~700 Mbps–Gbit** | Хабр NL 2024–26 |
| **AdminVPS** | 1 Gbit | Средний класс; отдельных iperf-листов мало | Агрегаторы + Хабр |
| **Hetzner** | 1–20 Gbit | Sustained **~900+ Mbps** в независимых EU-тестах | **RU mobile часто плохо** (блэклисты) |
| **Fornex / ishosting / 4VPS** | 1 Gbit (часто) | Сильный разброс; тостеры вечером проседают | Только свой замер |

**Вывод:** почти все пишут «1 Gbit». Для VPN важны **устойчивый** поток в час-пик и пинг с **вашего** ISP. Симметричный UL лучше для нескольких клиентов и Reality/HY2.

## Оплата / локация / роль

| Провайдер | Оплата из РФ | EU exit | Стабильность* | Поддержка* | Цена entry |
|-----------|--------------|---------|---------------|------------|------------|
| Timeweb | отлично | да | высокая | высокая | средне |
| VDSina | отлично | да | хорошая | хорошая | низкая–средняя |
| AdminVPS | отлично | да | хорошая | хорошая | низкая |
| Aeza | карты + крипта | да | железо топ / репутация 2026 спорная | быстрая | средняя |
| Fornex | часто крипта | да | спокойная | RU ok | средняя |
| ishosting | крипта+карты | да, много ДЦ | средняя | ok | средняя |
| 4VPS / FirstByte | РФ/крипта | да | тостер-лотерея | разная | низкая |
| Selectel/Beget/FirstVDS | отлично | слабее для exit | высокая (инфра) | высокая | разная |

\*Качественные оценки по отзывам, не SLA.

## Под FreshVPS

- Минимум **2 GB RAM**, KVM, Debian 12/13, публичный IPv4.
- Предпочтительно **EU** (FI/NL/DE).
- После заказа: 2–3 дня пинг + `iperf3` + туннель с телефона; второй хостер на другой ASN.
