# VPS providers (RU payment / VPN exit) — snapshot 2026-09

Сводка по открытым рейтингам и тестам. **Не замена** собственному `iperf3`/пингу с вашего оператора.

## Канал: заявленное vs замеры

| Провайдер | Типичный заявленный порт | Публичные замеры (ориентир) | Источник/комментарий |
|-----------|--------------------------|-----------------------------|----------------------|
| **Aeza** | 1–25 Gbit (локация) | Speedtest-снимки до **~700–800 Mbps** DL/UL на отдельных EU-нодах; в маркетинге «гигабит+» | Пользовательские Speedtest (напр. AMS); Хабр сильнее по CPU/disk, не всегда публикует iperf |
| **Timeweb** | 1 Gbit | В обзорах часто **сотни Mbps–~1 Gbit** DL; UL зависит от тарифа | Хабр NL/RU обзоры; сбалансировано |
| **VDSina** | до 1 Gbit | В бенчах mid-tier **сопоставим** с Timeweb по сети | Хабр сравнительные |
| **RUVDS** | до 1 Gbit | Дешёвые тарифы: **~900 Mbps DL / ~100 Mbps UL**; более дорогие — ближе к симметрии ~1 Gbit | Хабр «VPS по цене чипсов» / тесты VDS |
| **FirstVDS** | 100 M–1 G | В NL-обзорах сильный CPU; сеть **~700 Mbps–Gbit** в отдельных тестах | Хабр NL 2024–26 |
| **AdminVPS** | 1 Gbit | Средний класс; отдельных iperf-листов мало | Агрегаторы + Хабр CPU |
| **Hetzner** | 1–20 Gbit | Sustained **~900+ Mbps** в независимых EU-тестах | US/EU benchmark-статьи; **RU mobile часто плохо** (блэклисты) |
| **Fornex / ishosting / 4VPS** | 1 Gbit (часто) | Разброс сильный; тостеры вечером проседают | Нет единого iperf-листа — только свой замер |

**Вывод по каналу:** почти все пишут «1 Gbit». Реально для VPN важны **устойчивый** поток в час-пик и пинг с **вашего** ISP. Симметричный UL (не 100 Mbps) лучше для нескольких клиентов и Reality/HY2.

## Под FreshVPS

- Минимум **2 GB RAM**, KVM, Debian 12/13, публичный IPv4.
- Предпочтительно **EU** (FI/NL/DE).
- После заказа: 2–3 дня пинг + `iperf3` + туннель с телефона; держать **второй** хостер на другой ASN.
