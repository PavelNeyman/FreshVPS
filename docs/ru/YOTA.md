# Yota и белые списки

Yota — MVNO МегаФона, те же ТСПУ/БС.

## Что работает

- VLESS+Reality+Vision на 443, **IP в белом CIDR**, SNI разрешённого сайта.
- Дешёвый «просто RU VPS» часто **не** в БС → на LTE мёртво, дома по Wi‑Fi живёт.
- WG/OpenVPN в режиме БС обычно нет.

## Чеклист

1. С телефона без VPN: доступен ли TCP `IP_relay:443`?
2. Нет → сменить хостера (часто советуют Yandex Cloud).
3. Да, но VPN нет → сменить SNI (`api.vk.me`).
4. Дома — ссылка **core** (быстрее); мобильный — **relay**.
